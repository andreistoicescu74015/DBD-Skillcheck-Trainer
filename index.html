Profile auto-saves · Export / Import moves settings, stats and run history together · Rebind takes a key, a mouse button (M4 / M5 included) or a controller button. Reset settings wipes your calibration and asks first; it leaves stats and history alone.
A controller is invisible to the browser until you press a button on it, so press one before you hit Rebind. Button names are the standard layout, Xbox first and PlayStation second. A pad has no input events, only a buffer this page reads, so a press reads slightly later than a key and a little looser. That is the browser polling it and not you, so pad runs are saved and compared apart from keyboard runs.
